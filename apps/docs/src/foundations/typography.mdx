# Typography

| Role    | Family                                            | Used for                                             |
| ------- | ------------------------------------------------- | ---------------------------------------------------- |
| Display | Bricolage Grotesque (Noto Kufi Arabic for Arabic) | `h1`, `h2`, hero and stat numbers via `font-display` |
| Text    | Instrument Sans (Noto Sans Arabic for Arabic)     | Everything else via `font-sans`                      |
| Code    | JetBrains Mono                                    | Code and keyboard shortcuts only                     |

All fonts are self-hosted and licensed under the SIL Open Font License. Arabic families sit behind the Latin ones in each stack, so mixed and right-to-left text picks the right glyphs automatically.
