# Colors

Colors are OKLCH tokens exposed as CSS variables (`--tsl-color-*`) and Tailwind utilities (`bg-primary`, `text-muted-foreground`). Tailwind's default palette is removed, so only these exist. Every foreground/background pair is checked against WCAG 2.2 AA in `libs/tokens/test/tokens.spec.ts`.

Switch the theme in the toolbar to compare light, dark and oasis.

## Actions

`primary` is Tuareg indigo, the working color for actions and focus. `brand` is red ochre: use it for the brand mark and rare highlights, not for everyday buttons.

## Lines and focus

`border` is for decorative separators. `input` outlines form controls and meets 3:1 against surfaces, as WCAG 1.4.11 requires. `ring` is the focus indicator.
